💡 3-Minute Guide: How to create a Google Cloud OAuth Client ID ▼
  1. Go to the Google Cloud Console Credentials Page ↗.
  2. Create a new project (e.g. FotMob Calendar Sync) or pick an existing one.
  3. Enable the Google Calendar API from the API Library.
  4. Go to OAuth consent screen > Select External > Add your email. Under Scopes, add Google Calendar API (/auth/calendar.events). Under Test Users, add your Google email address.
  5. Go to Credentials > Click Create Credentials > OAuth client ID.
  6. Choose Application type: Web application.
  7. In Authorized redirect URIs, paste this exact URI:
    https://bebibnckeidijgchhcejbedinldcmfnn.chromiumapp.org/
  8. Click Create, copy the generated Client ID, paste it into the box above, and click Connect Google Account!
